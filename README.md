# RPX Encurtador de Links 🚀

Um encurtador de links premium, ultra-minimalista e de alta performance construído com **React**, **Vite** e **Firebase**.

## ✨ Funcionalidades
- 🔗 Encurtamento de links com slugs customizáveis.
- 📱 Design Responsivo e Moderno (Glassmorphism).
- 📊 Analytics detalhado (IP, Metadados, Localização).
- 🖼️ Geração automática de QR Code para cada link.
- 🔐 Autenticação via Google/Email.
- ⚡ Links diretos na raiz (ex: rpx-link.web.app/seu-codigo).

## 🚀 Como Publicar no Vercel

Este projeto já está pré-configurado para o Vercel!

1. Vá para [Vercel.com](https://vercel.com) e conecte sua conta do GitHub.
2. Clique em **"Add New"** > **"Project"**.
3. Selecione o repositório `encurtador-rpx`.
4. O Vercel detectará automaticamente as configurações do Vite.
5. Clique em **"Deploy"**.

### ⚠️ Importante:
O arquivo `vercel.json` já está configurado para que as rotas dos links curtos funcionem perfeitamente.

## 🛠️ Tecnologias
- **Frontend**: React 18, Vite, Framer Motion, Lucide React.
- **Backend**: Firebase Firestore, Firebase Auth, Firebase Hosting.
- **Deploy**: Vercel / Firebase Hosting.
